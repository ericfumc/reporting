Rules

      
    
        
  • H-score = (%1×1) + (%2×2) + (%3×3) (0–300)
    • 
        
  • Allred = proportion score (0–5) + intensity score (0–3)
    • 
        
  • Proportion uses % positive (%1+%2+%3): 0% → 0; <1% → 1; 1–10% → 2; 11–33% → 3; 34–66% → 4; ≥67% → 5
    • 
        
  • Intensity = average intensity, rounded half up: round(H-score ÷ % positive). If % positive is 0, intensity is 0
    • 
        
  • One line per intensity (0, 1+, 2+, 3+), with buttons 0–10
    • 
        
  • 0–9 means tens of percent (2 → 20%); 10 means 10%
    • 
        
  • The four percentages must total 100%
